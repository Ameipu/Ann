☁️ 雲端線上修改與 GitHub / Cloudflare 同步

本系統採用純前端靜態架構，無論是部署在 GitHub Pages 或是 Cloudflare Pages，您都可以隨時在線上更新名單與照片！

1

即刻在本機 / 目前手機生效（免重新部署）

您剛剛在後台修改的所有文字、桌號標記、名單，都可以一鍵保存在目前瀏覽器中，現場招待人員手機立即生效！

2

一鍵下載最新設定檔 (config.js)

將目前後台編輯的所有完整設定（含新人資訊、平面圖標記座標、賓客名單）下載為 config.js，直接放入專案的 js/ 資料夾即可。

3

如何在 GitHub 網頁上「直接線上修改」（免安裝任何軟體）

當您日後有新的賓客名單或新人照片網址時，甚至不需要打開電腦寫程式：

  1. 打開您在 GitHub 上的本專案倉庫頁面。
  2. 點進資料夾 js/，再點擊進入 config.js。
  3. 點擊右上角的「✏️ 鉛筆圖示 (Edit this file)」進入線上編輯器。
  4. 把剛剛複製的內容整段貼上覆蓋，或是直接在網頁上修改新人名字、桌號或賓客名單。
  5. 點擊右上角的綠色按鈕「Commit changes...」儲存！
  6. GitHub Pages / Cloudflare 會在 10 ~ 30 秒內自動重新發布，所有賓客掃 QR Code 就能看到最新名單！
